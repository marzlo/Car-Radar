權杖設定

網頁要代替你去 GitHub 按「Run workflow」和儲存議題，需要一組只能操作這個 repo 的權杖。只要設定一次，權杖只存在這台電腦的瀏覽器裡，不會上傳到 repo。

  1. 打開 GitHub 建立 Fine-grained token。
  2. Token name 隨意填，例如 car-radar-refresh；Expiration 選最長的。
  3. Repository access 選 Only select repositories → 選 Car-Radar。
  4. Permissions → 按 + Add permissions，勾選 Actions 和 Contents，兩個都改成 Read and write（Contents 是給網頁上編輯議題用的）。
  5. 按 Generate token，複製後貼到下面。

不想設定的話，也可以到 GitHub Actions 頁面 按 Run workflow，效果一樣。
