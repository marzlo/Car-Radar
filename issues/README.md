# 議題檔案怎麼寫

每個議題一個 `.md` 檔，上方 `---` 之間是設定，下方每個 `## 日期 | 標籤` 是一筆時間軸紀錄。

```
---
title: 議題名稱（建議寫成問句）
status: keep        # keep=觀點維持 / revise=修正中 / flip=已推翻 / watch=觀察中
since: 2024-05-05   # 開始追蹤的日期
keywords: [智駕, NOA, FSD]   # 新聞標題含這些字，就會自動掛到這個議題
metric: cn_nev      # 選填：相關數據（cn_nev 或股價代號，例如 TSLA）
then: 當時的判斷，一句話
now: 現在的判斷，一句話
---

## 2024-05-05 | 我的判斷
內容……

## 2026-10-05 | 回顧
內容……
```

想改觀點時：改 `now` 和 `status`，再往下加一筆有日期的紀錄。舊的紀錄不要刪，這樣才看得到變化。
